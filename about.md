# StartPos Editor

Have you ever wanted to add start positions to any level, including RobTop levels? Well, you don't need to wish anymore. This mod lets you add start positions to any level and use them.

## Features
- Opens the real level editor on any level (online, your own, and main levels via the info button), locked so only start positions can be placed, moved, edited or deleted.
- Edit start position settings (game mode, speed, mini, flipped gravity) with the normal edit popup.
- Start positions are saved per level; the level itself is never changed.
- Pick which start position to use, or play from 0%.
- Works with capeling's StartPos Switcher to cycle through them in-game.
